# pj_katan

カタンの配置に基づく資源獲得期待値を比較する、スマートフォン対応のWebアプリです。
HTML・CSS・JavaScriptだけで動作し、サーバーや外部ライブラリは不要です。

## 機能

- 3〜6人を、赤・青・白・オレンジ・茶色・緑の順で管理
- プレイヤーごとに複数の開拓地・都市と、各建物に最大3つの隣接タイルを登録
- 建物ごとに貿易港を登録し、所有港をサマリに表示
- 資源別の獲得期待値と合計を、全プレイヤーの表で比較
- レーダーチャートで資源バランスを比較し、線の表示を切り替え

期待値はサイコロ1回あたりの獲得枚数です。都市は2倍で計算します。
港は交換比率を記録する項目で、獲得期待値には影響しません。
同じ種類の所有港はサマリに1回だけ表示します。

## ローカルで確認

`index.html` をブラウザで開いてください。依存関係のインストールやビルドは不要です。
ローカルHTTPサーバーを使う場合は、リポジトリのルートで次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

その後、ブラウザで `http://127.0.0.1:8000/` を開きます。

## GitHub Pagesで公開

GitHubリポジトリの **Settings → Pages** で、次を設定してください。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

公開が完了すると、Pages設定画面にサイトURLが表示されます。

## 初版の仕様

- 初期人数は3人で、赤プレイヤーにサンプル配置があります。
- 入力はブラウザのメモリ内で保持し、再読み込みするとリセットされます。
- 人数を減らして非表示になったプレイヤーの入力は、再読み込みするまでは保持されます。
- 盗賊の影響、資源カードの在庫不足、建物配置の合法性は計算に含めません。
